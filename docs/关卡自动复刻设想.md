# 关卡自动复刻设想

## 转换目标

将官方关卡数据转换为可在关卡制作器中继续修改的关卡文件。转换器应保留来源版本、所选规则和分支取舍，方便人工对照地形、敌人及波次。

## 输入与转换

| 输入 | 转换内容 |
|---|---|
| 关卡 JSON 的地图与地块定义 | 地形、可部署范围、出入口与坐标对应 |
| 路线、波次和出生动作 | 路线模板、独立出生、时间与停留 |
| 关卡选项与规则字段 | 部署上限、目标生命上限、初始费用及数值修正 |
| 集成战略主题表 | 关卡清单、主题标识与可选难度规则 |
| PRTS 关卡备注与敌方情报 | 核对特殊分支、数量和机制语义 |

现有部署上限和目标生命字段可直接承接转换结果；尚未支持的关卡规则需先扩展数据契约与战斗读取，不能仅写入文件后视为生效。

地图转换需结合地块索引与地块定义，明确坐标原点、行方向和路径位置。关卡中的随机组、隐藏组、互斥包及预置装置应分别解释，不能统一取第一条或全部展开。

## 主题档案

用主题档案描述难度档位、环境选项、分支规则及主题专属机制，由通用转换器读取。普通／紧急的倍率来自具体关卡规则，不按主题或全部关卡写死。

档案负责解释原始字段，关卡文件保存实际采用的分支与折算参数。仍依赖整轮进度、收藏品或主题资源的效果，应独立列出所需条件，不假装单张地图已经完整复现。

## 编辑器衔接

转换后直接在制作器中打开草稿，提供来源、数量差异和分支取舍供人工核对。主题、规则难度、紧急状态与环境面板属于后续编辑能力；展示用星级保持独立。

## 尚需完成

建立通用转换器、主题档案、地形映射与随机分支解释，扩展尚不支持的关卡规则，并用不同主题的关卡逐一对照。固定布局的数据转换与完整三维场景接入分开处理。
