# 自由沙盘存档

存档保存按下保存时的现场。单位列表从当前战场读取，只保留仍存活、已部署且血量大于零的干员与敌人；历史部署记录、已撤退、已击倒、已漏出的单位和未出生队列不进入新存档。载入后统一暂停，空格继续。

## 保存内容

| 内容 | 保存范围 |
|---|---|
| 地图 | 地形、战场范围、地图路线、装置及地图自身其他字段 |
| 在场干员 | 身份、当前位置、朝向、所选技能、部署顺序、血量、技力与攻击冷却 |
| 在场敌人 | 身份、当前位置、倍率、钉住设置、剩余路线、剩余中继停留时间、血量与攻击冷却 |
| 手牌 | 名单、顺序与各干员的技能选择；独立于场上单位 |
| 演练状态 | 时间、费用、击杀数、漏怪数、四类伤害计分与最近 5 秒伤害窗口 |
| 演练设置 | 2D／3D、倍速与部署是否扣费 |

移动敌人从保存时的位置沿剩余路线继续，不回到原路线起点。地图修改触发战场重建时，也以修改前仍在场的单位为准。新地图默认 3D、1 倍速、不扣费。

计分板统计保存在 `session.score`，读档与地形重建保留累计伤害和近 5 秒 DPS。旧档没有计分字段时从零开始；「清零」只重置统计，重置演练与新地图清零。

进行中的技能、异常状态、元素槽、阻挡与目标关系、弹道、召唤过程和视听效果不作为完整战斗帧恢复，进入新战场后重新计算或产生。保存的血量按重新初始化后的生命上限截断，技力按所选技能的充能上限恢复。

## 存档操作

六个槽位支持新建、载入、覆盖、删除与指定目标复制。载入某槽位，或将当前现场手动写入某槽位后，该槽位成为当前存档位；界面「管理存档」旁显示编号。

「快存」无需确认，直接覆盖当前存档位。尚未绑定槽位时自动使用一个空槽。若六槽已满且未绑定槽位，打开存档管理，由用户选择目标，避免覆盖其他存档。

「新建地图」先把当前现场保存到当前槽位，再直接进入新的空地图。未绑定槽位时先使用空槽；满槽时先完成存档选择。保存失败时保留当前现场，不继续新建。返回开始菜单进入沙盒／关卡编辑器选择页，当前编辑副本会自动保存。

## 重置演练

「重置演练」放在右侧独立位置，远离播放与倍速控件，操作前需确认。它保留当前地图和仍在场的单位，重置演练时间、血量、技力与费用，并暂停；不会从历史记录中复活已退场单位。地形工具中的恢复空白沙盘会再次确认，并按新建地图流程先保存现场。

## 本地存储与旧档

现场内容使用 `format:3`，继续沿用 `arksim-sandbox-v3` 与六槽库 `arksim-sandbox-slots-v1`。当前槽位编号保存在当前浏览器标签页的 `sessionStorage`，全局声音与显示设置保存在 `arksim-sandbox-settings-v1`，独立于地图槽位。清除网站数据会删除本地内容。

原五槽库保留原有槽位，第六槽补为空位；存储键和版本不变。旧版存档仍可读取，但缺少当时的战场状态，不能反推出哪些单位已经退场。旧版列表按已有内容加载；再次保存时，按当前实际在场单位写成新格式。早期地图存档从未记录的场上单位无法补回。
