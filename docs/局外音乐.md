# 局外背景音乐

主菜单、自由沙盒存档页、关卡游玩与编队页、关卡库和实际关卡编辑界面共用局外音乐。进入自由沙盒或关卡战斗后停止局外音乐，关卡战斗继续读取关卡的 `meta.bgm`。

## 选择曲目

局外音乐默认选择《生命流》。在页面角落打开全局设置，在声音区域的「局外音乐曲目」中选择音乐，切换后立即播放，选择保存在当前浏览器中。

局外设置与关卡编辑器共用 `content/music/` 中的 OGG 曲目，通过 `/api/music` 获取列表。加入新的 OGG 后，打开全局设置或点击「刷新曲目」即可选用，无需重启服务。关卡的作战音乐仍由关卡编辑器单独选择。

## 播放与音量

页面角落的音乐按钮即时开关局外音乐；全局设置中的背景音乐音量、静音和局外音乐开关共用 `arksim-sandbox-settings-v1`。初次播放等待点击或按键，以满足浏览器的音频手势要求。局内快捷键仍在局内设置中配置，自由沙盒与关卡战斗共用这些键位。

`public/sandbox/js/menu-audio.js` 负责曲目选择和界面音效，播放沿用 `level-bgm.js`。OGG 内的 `LOOPSTART`、`LOOPLENGTH` 以采样数表示，播放器使用 `LOOPSAMPLERATE` 或 Vorbis 文件头中的源采样率换算循环秒数，避免声卡采样率不同引起循环偏移；缺少循环标签时整曲循环。OGG 随源码提交，Git 克隆和源码 ZIP 都包含已发布曲目。

主菜单和二级页面使用项目已有 `g_ui_btn_u`、`g_ui_btn_h` 音效，经过低通、音量和触发间隔控制。实际关卡编辑工具不播放这些交互音效，也不应用局外按钮动效；页面角落的全局控件仍可使用。
