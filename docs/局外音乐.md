# 局外背景音乐

主菜单、自由沙盒存档页、关卡游玩与编队页、关卡库和实际关卡编辑界面共用局外音乐。进入自由沙盒或关卡战斗后停止局外音乐，关卡战斗继续读取关卡的 `meta.bgm`。

## 放置与配置

音乐文件放在 `content/music/`，配置写在 `content/menu-music.json`。当前配置的 `tracks` 为空，因此不会自动选择已有作战曲作为局外音乐。

原始分段放在不入库、不提供下载的 `content/music/original/`。同名 `*_intro` 与 `*_loop` 表示已经确定边界，运行 `node tools/music-loop.mjs` 直接合成 OGG：intro 一次，loop 循环，不另行裁剪或淡化。文件名前的数字序号不影响配对，成品输出到音乐目录根层。

例如，将制作完成的 `menu.ogg` 放入音乐目录后，可使用以下配置：

```json
{
  "tracks": [
    {
      "file": "menu.ogg",
      "name": "主界面音乐",
      "scenes": ["home", "sandbox", "play", "editor"]
    }
  ]
}
```

| 字段 | 含义 |
|---|---|
| `file` | `content/music/` 中实际存在的文件名，不含目录 |
| `name` | 曲目名称，省略时使用文件名 |
| `scenes` | 适用入口：`home` 主菜单、`sandbox` 沙盒存档页、`play` 选关与编队、`editor` 关卡库与编辑界面；省略或留空时适用所有局外入口 |

按配置顺序选取第一首适用曲目。`/api/menu-music` 只返回音乐目录中存在的 OGG；MP3 等源文件不列入接口，也不能通过 `/music/` 下载。修改配置或添加文件后重新进入页面即可读取。

## 播放与音量

页面角落的音乐按钮即时开关局外音乐；全局设置中的背景音乐音量、静音和局外音乐开关共用 `arksim-sandbox-settings-v1`。初次播放等待点击或按键，以满足浏览器的音频手势要求。局内快捷键仍在局内设置中配置，自由沙盒与关卡战斗共用这些键位。

`public/sandbox/js/menu-audio.js` 负责曲目选择和界面音效，播放沿用 `level-bgm.js`。OGG 内的 `LOOPSTART`、`LOOPLENGTH` 以采样数表示，播放器使用 `LOOPSAMPLERATE` 或 Vorbis 文件头中的源采样率换算循环秒数，避免声卡采样率不同引起循环偏移；缺少循环标签时整曲循环。OGG 与配置随源码提交，Git 克隆和源码 ZIP 都包含已发布曲目；`original/` 与 MP3 等源文件继续排除在 Git 之外。

主菜单和二级页面使用项目已有 `g_ui_btn_u`、`g_ui_btn_h` 音效，经过低通、音量和触发间隔控制。实际关卡编辑工具不播放这些交互音效，也不应用局外按钮动效；页面角落的全局控件仍可使用。
