# Windows 发行版设想

## 便携运行环境

优先提供 Windows x64 压缩包，包含独立 Node.js、安装完成的运行依赖、前端库、程序数据、自设素材和已发布的 OGG 音乐。玩家解压后双击启动，无需安装 Git、Node.js 或输入 npm 命令。

## 素材下载界面

首次启动界面提供「下载素材」和「先进入界面」，展示预计流量、空间和保存位置。下载中显示进度，失败可重试并复用已完成文件。可选增强素材由玩家主动选择，沿各自来源与授权范围获取。

## 存档迁移

提供沙盒存档和编队的导入、导出入口，便于更换浏览器或电脑。关卡文件、用户音乐与浏览器中的沙盒存档分别迁移；稳定本机访问地址，避免更新改变存储来源。

## 更新包

程序与大体积素材分开更新，只补充所需文件。更新应保留玩家关卡、音乐、素材缓存及导出的存档，每个发行包附对应源码版本、使用说明和第三方许可文件。
