# Windows 发行版设想

## 使用目标

提供面向普通玩家的下载入口：下载压缩包、解压、双击启动，随后在浏览器中使用自由沙盒、游玩自制关卡和关卡制作器。玩家无需安装 Git、手动安装 Node.js 或输入 npm 命令。

## 包的组成

首个发行版优先面向 Windows x64，随包提供独立的 Node.js 运行环境、安装完成的运行依赖、前端库、程序与数据、自设素材和已发布的 OGG 音乐。源码仓库继续保留，供修改代码和内容的使用者选择。

官方素材沿用公开资源下载方式，由首次启动界面提供「下载素材」和「先进入界面」两个入口。下载前显示预计流量、所需空间与保存位置；下载中显示进度，失败后允许重试并复用已完成文件。公开下载尚未覆盖、需要本地提取的资源另列为可选增强项，由玩家主动开启。

## 启动与保存

启动器使用包内的运行环境，打开默认浏览器；关闭启动窗口时结束本次服务进程。再次启动可以复用已下载素材，无需重新准备依赖。

浏览器中的存档与编队仍保存在该浏览器的网站数据中。发行版应保持稳定的本机访问地址，并提供存档导入、导出入口，避免玩家因更换浏览器、改变地址或清理网站数据丢失内容。

## 更新方式

程序更新与大体积素材更新分开提供。更新时保留玩家导入的关卡、音乐、素材缓存与存档导出文件；新版本有新增素材时，只补充所需文件。每个发行版附对应源码版本、使用说明和第三方许可文件。

## 当前使用方式

当前仍按源码版方式安装和启动。独立运行环境、首次启动下载界面、发行包构建和更新流程属于后续实现范围。
