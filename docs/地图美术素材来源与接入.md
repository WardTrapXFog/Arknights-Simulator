# 地图美术素材来源与接入

## 已有数据与素材

2026-10-26 通过 PRTS-MCP 3.1.2 的 `get_stage_info` 查询 `main_01-07`，返回关卡信息和关卡 JSON 路径。该工具用于定位关卡规则与布局，没有返回 Unity 地图网格、场景材质或光照贴图。当前 MCP 的干员图片工具提供干员立绘，不提供地图场景二进制素材。

[AKDP Release](https://github.com/3aKHP/arknights-data-pipeline/releases/tag/data-26-10-22-14-02-11-51447808) 的 `data-26-10-22-14-02-11-51447808` 发布包提供 `zh_CN-levels.zip`、`zh_CN-excel.zip` 等结构化数据；对应图片发布包提供图片资源。关卡 JSON 可用于对照地形与路径，不能替代完整地图场景的模型与材质。

项目本地已经存在 `public/assets/local/scene/` 场景导出，包括 `act1autochess_m01` 至 `act1autochess_m07`、`act2autochess_m01` 至 `act2autochess_m04` 及纹理资源。`tools/local-extract/scenes.py` 导出 Unity 场景网格、材质、纹理、光照贴图与环境信息，依赖场景引用的资源包；`fetch_scenes.py` 提供已知版本和场景名的资源下载入口。本次没有新增解包，也没有读取、修改或启动官方游戏客户端。

## 当前渲染入口

| 位置 | 已有能力 |
|---|---|
| `public/js/render/board3d/load.js` 的 `loadBoardPack` | 加载可拼装棋盘使用的地块模型与纹理图集 |
| 同文件的 `loadScenePack` | 按素材登记表中的场景组和关卡 ID 加载完整官方场景 |
| `tools/local-extract/scenes.py` | 将固定官方场景导出为场景数据、网格、材质纹理和光照资源 |
| `public/level/js/terrain.js` | 使用网格、CSS 地块和 SVG 路线编辑逻辑地图，不加载完整官方三维场景 |
| `shared/level-preview.js` | 根据逻辑地形生成关卡简图 |

完整场景通常包含合并后的网格、场景专用 UV、烘焙光照及装饰。改变一个逻辑地块的高度或通行类型，不会自动重切网格或重烘焙光照。因此，完整官方场景适合固定布局的场景模板；自定义地形需要能重复拼接的地块素材。

## 可行的接入路径

自由编辑地图可扩展现有 `loadBoardPack`，为高台、地面、不可通行区、边缘和转角提供主题化网格或图集。编辑器继续写现有逻辑地形，渲染层按主题选择外观。部署区、寻路、阻挡与伤害判定继续读取逻辑网格，不从装饰模型反推。

复现固定官方地图可复用 `loadScenePack`，建立关卡 ID、完整场景和逻辑网格的对应关系，明确原点、格长、高台高度与目标点位置。此类模板需限制会破坏场景对应关系的地形编辑，保留敌人、路线与出生编辑。场景坐标对齐后才能接入，不能仅凭关卡 JSON 中的地形编号直接显示官方场景。

若要补充新素材，先用 MCP 定位关卡和主题，再确认 AKDP 发布清单是否包含所需图片；三维场景使用已有导出器所需的资源包和依赖。素材导出进入本项目的 `public/assets/local/`，登记表进入现有素材加载链。官方美术继续按仓库规则排除在 Git 之外；仓库的 GPL-3.0-or-later 不覆盖游戏素材，素材权利归原权利人。

现阶段具备结构化关卡数据、固定官方场景导出器和两类渲染入口。尚未取得可供任意编辑地图使用的完整主题地块集，也未建立新关卡与官方场景的坐标对应表；本次保留当前编辑器地形表现。
