# 地图美术接入设想

## 主题地块

自由编辑地图需要可重复拼装的地面、高台、围墙、边缘与转角素材。可在 `public/js/render/board3d/load.js` 的地块加载链上扩展主题外观，制作器继续编辑逻辑网格。

部署、寻路、阻挡与伤害判定始终读取逻辑网格，装饰模型只负责表现。主题地块还需确定格长、高度、接缝与材质，避免改变地形后出现断面或错位。

## 固定官方场景模板

固定地图可沿现有 `loadScenePack` 接口接入完整场景，但仍需建立关卡、场景与逻辑网格的对应表，完成原点、格长、高台、出入口的坐标对齐。

完整场景包含合并网格、专用 UV 与烘焙光照。此类模板应限制破坏场景对应关系的地形修改，保留敌人、路线与出生编辑；不能把一个逻辑地块变化直接当成网格和光照同步变化。

## 素材来源与边界

PRTS-MCP 与 AKDP 的关卡数据用于定位布局和规则，不提供可直接替代场景网格、材质与光照的地图 JSON。图片发布包需按清单确认具体内容；三维场景可以沿 `tools/local-extract/scenes.py` 所需的资源包与依赖导出。

新素材接入前需确认来源与使用范围，再进入素材登记和加载链。仍需补齐任意编辑地图的主题地块集、固定场景对应表及编辑限制，当前制作器的网格表现继续保留。
