## 运行范围

本地默认战斗已使用单个 AUE 世界，现有自由沙盒、游玩自制关卡和关卡制作器的页面、关卡文件、沙盒存档及渲染器保留。明确使用 ?engine=legacy 才加载旧引擎。没有在同一场里同时推进两个引擎，也不在失败后静默回退。

464 个可选槽位包括原有 202 个原作／补位槽位、三名自设和新增 259 个 AUE 原生槽位。原有槽位继续使用本地 kit，新槽位使用从固定 AUE 训练数据生成的职业、技能、天赋及配装定义。数据收录不表示所有机制均已实现。

259 条敌人记录均可转换并进入战斗。圆石技艺与螺旋桨保留项目已有能力；原生未覆盖的其他敌人使用已登记的本地敌人／领袖能力。原生和本地处理按单位互斥，不删除未知能力以绕过检查。转换保留技能 bb；攻击／SP 技能的负计时哨兵不传给只接受非负秒数的原生计时器。

## 复现

日常启动仍用现有启动脚本。服务会自动在本地展开随仓库的引擎源码包，后续启动复用同一包的缓存；不要求玩家 clone AUE 或安装 pnpm。

开发检查按需要分别执行，避免每次重复全量运行：

    node tools/exercise-aue-trial.mjs --contracts
    node tools/exercise-aue-trial.mjs --skills
    node tools/exercise-aue-trial.mjs --enemy-combat
    node tools/exercise-aue-trial.mjs --session --http

结果写入本地 .agent-runs/。新增干员的模型、头像和语音已加入既有素材下载计划；本轮没有执行网络素材下载，缺少的官方素材继续由 npm run assets 获取。

特殊地形、装置、封锁边与传送仍明确拒绝，未伪装成普通地图。现场恢复保留既有范围，没有升级为完整状态、弹道和技能过程的逐帧快照。生成源码额外公开原生元素模块已有的 burst 与 beginning，供塔露拉主动爆发和重入保护使用；另在原生费用阶段提供可选的宿主回调。两者均是后续升级需核对的接口依赖。
