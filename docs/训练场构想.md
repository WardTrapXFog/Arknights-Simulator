# 训练场构想

## 可调干员练度

训练同一关卡时，应能按玩家实际阵容设置精英阶段、等级、潜能、信赖、技能与模组等级。满配牌库继续作为预设，可选的练度配置属于玩家编队，不写入关卡文件。

属性与技能应从官方表计算，不用统一倍率代替成长曲线。技能和模组的可选等级受精英阶段及各干员实际档位约束；自设干员继续使用自己的已确认定义。编队切换、重新部署与再次作战都需保留所选练度。

## 集成战略规则面板

提供主题、难度档位、普通／紧急、环境与敌人数值倍率的配置。现有难度星级只承担展示作用，不能充当规则难度。

关卡规则可以同时保存语义选项与折算后的敌人参数；用户手动修改折算值后应标明差异，避免再次选择难度时无提示覆盖。主题规则与转换流程见[关卡自动复刻设想](关卡自动复刻设想.md)。

## 训练反馈

为同一关卡保留尝试次数、最佳成功用时与失败时的波次位置，帮助比较阵容和操作。每次尝试应能区分关卡版本、阵容与练度配置；结算时已有的单次伤害计分继续作为当次记录来源。

## 实施顺序

先支持实际练度，再提供主题规则面板与关卡转换，最后增加多次尝试的对比。干员按具体训练需求补充，不以收录全图鉴为前提。
