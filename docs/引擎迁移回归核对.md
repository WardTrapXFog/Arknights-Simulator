# 引擎迁移回归核对

2026-10-30。固定引擎版本为 `b25523619c981cb1380928ffe96b0fcd67263e74`。本轮依据现有源码与 PRTS 机制备注修正适配，不运行测试、服务或浏览器；以下是代码落实范围，不代表玩家实测结果。

## 共用接口修正

| 范围 | 查明的差异 | 当前处理 |
|---|---|---|
| 部署地形 | 实际部署把所有非 RANGED 单位当作地面单位，遗漏 ALL；预览与部署各有一份规则 | 共用 `shared/deployment.js`；手牌和 AUE 实际部署共用判定，兼顾原生职业与所属干员的高台许可 |
| 费用表现 | 费用事件使用 `dp`，现有飞字层消费 `dpGain`；嵌套回调缺少来源单位 | 复用原有账户方法，恢复回调来源栈；原生产费也进入同一入口，继续使用既有 620 毫秒飞字显示延迟 |
| 费用规则 | 原生账户没有本地费用下限与自然回复事件；负费用阶段未减半 | 保留本地可支付判定、上下限和 `dpRegen`，在原生自然回复阶段计算，保留原生回复倍率与费用封锁 |
| 召唤物身份 | 动态召唤物补上原生 summoner 后，查询可能重新包装，丢失原有 mem、kit 和归属形状 | 优先取持久单位；本地召唤物继续由手牌与 kit 管理生命周期，原生召唤物保留原生归属和寿命 |
| 召唤物默认机制 | 没有显式传入 kit 的召唤物未安装本地默认 kit | 接入本地 token 工厂与共用召唤钩子；保留干员显式指定的召唤物 kit，原生定义不重复安装本地默认 kit |
| 召唤物固有状态 | 数据中的不可选中、禁疗、孤立没有补入单位 | 初始设置写入持久状态，重新部署时恢复 |
| 护盾 | 本地 buff 参数中的护盾值、护盾层数未写入原生 buff，包装也没有层数读写 | 接通原生护盾字段和层数接口，既有 kit 继续读取同一状态 |
| 攻击范围 | 离场单位设置 rangeGrid 时被忽略，部分安装期调整无法带入部署 | 保存范围覆盖，在实际建单位时写入原生范围；保留数组引用供既有 kit 比较 |
| 表现投影 | 会话缺少 kit 弹道及弹药、狼影、负血量、硬币、蓄能、护盾层数、技能充能、元素条的附加快照 | 恢复原有渲染契约，读取真实状态，不另行模拟数值 |
| 延后出生与结算 | 定时任务的 holdsBattle 未保留；原生清场结果不认识本地待出生队列 | 带此标志的任务、待出生敌人或仍存活敌人阻止成功结算，生命耗尽仍立即失败 |

望的手动棋子、跟子顺序、连线、失气与伤害规则继续由原有 kit 执行。本轮修正其所在的召唤物初始化、身份、部署及表现通路，不改写这些已确认的规则。朝向、库存、费用、占位、持有者离场与冷却继续使用既有手牌策略；本地召唤物与原生召唤物的生命周期分开接线。

## 机制依据

PRTS「可露希尔」天赋及「指挥中心」备注明确：指挥中心可部署于地面与高台，限所属干员攻击范围；被击倒或撤退后进入战术点形态；所属干员离场时撤离。PRTS「部署费用」及可露希尔相关备注明确负费用时自然回复减半。此次修正恢复 ALL 部署与费用执行路径；不将项目的产费飞字延迟当作原作到账延迟。

其余修正以本项目旧引擎的 `battle/deployment-hand.js`、`battle/economy.js`、`content/tokens.js`、`snapshot.js`、`battle/events.js` 与相同本地 kit 为对照。保留本地实现不等于适配接口已经自动等价，前轮短场景无异常也不能证明机制与表现相同。

## 启动准备信息

启动器先从随源码提供的运行包准备 AUE 缓存，再显示默认引擎版本、实际运行文件数和牌库组成。缺少缓存文件时重新展开，不依赖维护者的 AUE 仓库。牌库数据缺失或版本不符阻止启动；可选美术与特效仍为提示。已移除的官方棋盘不再出现在准备摘要中。

生成工具在固定源码中保留元素内部接口导出，并增加可选的自然回复与产费回调；未配置回调时保留原生逻辑。升级 AUE 时需核对这些源码位置、回调参数与执行阶段，和本地适配一起生成交付包。
