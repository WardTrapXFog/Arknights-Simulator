# 塔露拉官方素材动作实测与状态衔接

## 素材与计量口径

使用 `public/assets/spine/enemy/enemy_1503_talula/` 中的原始 `.skel`、`.atlas`、`.png`。骨架版本为 Spine 3.8.99，含 97 根骨骼、50 个插槽、8 段动画，贴图为 512×512。文件指纹写在同目录的 `animation-spec.json` 中。该 JSON 保存选片、源相位、播放映射、状态优先级与混入参数；本文说明每段素材实际呈现的动作及选用理由。

本文的“源秒”指素材自身时间，“游戏秒”指随暂停与倍速推进的表现时间。源帧按 30fps 计，源秒等于源帧除以 30；归一化源相位等于源秒除以片段时长。浮点末帧以 JSON 中读取的实际时长为准，允许 0.00001 秒误差。`Default` 时长为零，只有相位 0，不能参与除法或循环计时。

八段均直接读取了骨骼旋转与位移关键帧，并查看从头到尾每 0.1 源秒的纹理网格帧及精确末帧。另查看了以下连续 30fps 帧：`Attack_1` 0.8–1.2 秒、`Attack_2` 1.2–1.6 秒、`Skill_1` 0.8–1.2 秒、`Skill_2` 2.4–2.8 秒、`Die` 4.5–4.9 秒。事件、掌拳切换、原生刀痕显隐和死亡透明度同时与关键帧数据对照。

图像由项目已有 Spine 3.8 运行时计算当前姿势、IK、加权网格和变形顶点，再用原图集在内存中拼成纹理帧。观察的是角色自身连续姿势，不含游戏场景和程序特效。没有启动服务、运行游戏或进行浏览器验收，也没有另存截图、脚本或测量流水文件。下文的素材时间、事件与角度是实测数据；混入时长、重定时和外层位移是选定的接入参数，尚未经实机观感验收。

## 必须区分的四种角度

骨骼的设置姿势角、动画旋转关键值、动画中的变化幅度、最终世界角度不是同一个数。`R_Weapon` 的动画旋转关键值全部为 0，但设置姿势局部角为 −46.095516°。它的父骨是 `R_Hand`，因此手臂与手的运动仍能让剑在世界空间里大幅转动。不能把“动画旋转值为 0”解释成剑始终朝同一个世界方向。

`Attack_2` 的 `Chest` 关键值固定为 −9.6858°，`Head` 固定为 −16.5138°，两者自身的旋转变化幅度确为 0。腰和上游骨骼变化、IK 与网格变形仍会带动它们的世界位置与方向。因此，这段缺少胸头主动配合的发力动作，但并非整个身体的世界矩阵完全静止。

`Attack_1` 的 `L_Hand` 旋转关键值跨度为 54.4324°，`Attack_2` 为 28.8529°。这个比较指的是左手，不是持剑右臂，更不是剑刃的世界角度。连续帧显示前者主要在做张掌施放，不能据此把前者称为更有力度的剑击。

题述中另两项需要收窄口径：`Skill_1` 的 `L_Hand` 自身旋转变化幅度为 0，但 `L_Arm` 的关键值跨度为 93.0918°，上臂会将整只手抬起；胸部变化幅度为 7.8411°，头部为 2.1647°。`Idle` 也并非全骨骼旋转恒定：在按 360° 等价处理后，97 条旋转通道中有 53 条的关键值变化超过 0.001°，其中包含衣发、尾巴等骨骼。右上臂幅度为 0.5449°，右手为 1.3775°；胸、头、左手和剑骨的自身旋转幅度为 0。本文保留这些真实差异，规格不新增手腕翻转、胸头发力或其他素材中没有的骨骼动作。

## 八段素材实际在演什么

### Default：持剑站姿，没有入场过程

唯一姿势是身体直立、剑在体侧斜向下伸出。它没有持续时间、迈步、抬眼、剑尖落地或出场淡入。作为重建时的静态兜底可用；不能反复播放成待机，也不能把它标成一段部署表演。

### Idle：低位持剑，附带衣发和尾巴摆动

0–3 源秒始终维持同一持剑构图，剑没有经历抬起再劈下的完整剑路。尾巴明显摆动，衣发、手臂和网格有小幅变化。0 与 3 秒回到相接的姿势，适合整段循环。

其胸部位移关键帧为 `(0,0,0)`、`(1.5,−1.9351,0.4147)`、`(3,0,0)`；头部也在 1.5 秒有 `(−1.4153,0.2488)` 的局部位移偏移。这里的坐标是骨架源单位，不能直接写成屏幕上的“呼吸两像素”。左上臂关键值 −29.0706°、330.5136°、335.9375°、−29.0706° 跨过了 360° 表示边界，不能按原数值最大减最小误报成转了一整圈。

普通待机、S1 等待强化攻击、S2/S3 无目标时均使用完整 0–90 帧。需要表现“屏住呼吸”时，直接混入并定格 `Idle(0)`，停止这段原生的小位移与变形；不能只把胸骨旋转置零，因为它原本就没有旋转变化。低血和曝光等差异交给随身特效，不再添加胸部或剑骨动画。

### Move：原地迈步，没有走进或走出战场

0–75 帧呈现持剑交替迈步，身体姿势接近待机，腿脚、衣摆和尾巴组成循环。第 16、55 帧有两次 `OnPlayEffect`，适合作为原素材的步态相位参照。`root` 没有跨格位移；`bone` 只有固定平移偏移，不提供人物从画面边缘走到部署格的运动路径。

本规格不使用 `Move`。固定部署的干员原地踏步会让撤退看起来像卡住，给它额外移动路线又会扩大现有表现和位置语义。入场与撤退都采用静态姿势配合外层透明度，明确接受缺少专用动作的限制。

### Attack_1：左手收拢、张掌前送，不是大剑劈砍

0–13 帧抬起左手；第 13 帧掌切换为拳，13–29 帧保持收拢蓄势；第 29 帧拳换回掌，第 30 帧 `OnAttack` 附近左手张开向前送出。33–60 帧，胸头和左臂逐步回收，剑仍主要停在体侧下方。

连续 0.8–1.2 秒的画面能清楚区分“收掌—张掌前送”，但看不到 `Attack_2` 那种举剑过肩再向前劈的完整路径。胸部旋转幅度为 5.2063°，头部为 10.5396°，左手为 54.4324°，这些变化让施放更活跃，却不构成剑击更强的证据。`F_R_Weapon_E` 全段为空，也没有原生挥剑刀痕。

这段保留为可识别的官方施放素材，本规格不选它做普攻、S2 或 S3。S1 已使用先抬掌后收掌的 `Skill_1`，不再混入第二段施放去增加动作次数。

### Attack_2：抬剑到肩后，再短促前劈

0–22 帧，剑从体侧移过下方并抬起；22–37 帧举到肩后；37–39 帧短暂准备；39–44 帧完成主要前劈和展开；44–70 帧横剑收势并归位。第 40 帧 `OnAttack` 为真实素材命中参照，`F_R_Weapon_E` 在第 40 帧显示、第 44 帧隐藏。它是一块随素材出现的灰色大片刀痕，不是新火效所需的薄刃月牙。

连续帧中，1.3 秒剑还在肩后；1.3333 秒已向前送出；1.3667 秒剑向下经过前方；1.4 秒已到身体另一侧下方；1.4667 秒进入横剑余势。以运行时默认 `yDown=true`、未做角色镜像的剑轴计算，世界角度依次约为 −119.783°、−13.6941°、55.628°、149.2591°、173.9607°。这些变化来自手臂父链，剑骨局部角仍固定。

普攻与 S2 使用整段 0–70 帧，压缩前奏并保留清楚的实挥与收势。缺少胸头自身发力是这段的真实短板；不能通过更大的火光宣称已经获得新的身体动作。现有配置将命中处映射到约 1.42 源秒，已经越过原生 `OnAttack`，本规格恢复到第 40 帧，不再用晚相位冒充命中帧。

### Skill_1：上臂抬掌，命中时收掌换拳

0–14 帧左上臂把手掌抬到面前；14–28 帧张掌保持；28–30 帧开始收拢；第 30 帧 `OnAttack` 与 `F_L_Palm → F_L_Fist` 切换同相位发生。30–55 帧维持握拳余势，第 55 帧换回掌，至第 60 帧放下。

`L_Hand` 的旋转和局部平移偏移均不变，不支持单独转腕、翻掌或一套手指握火动画。不过父链确实移动了手：在未镜像的运行时骨架坐标中，左手骨原点从源 0 秒约 `(37.4519,−166.1297)`，移动到 0.6667 秒的 `(106.6968,−256.5007)`，命中时约 `(104.6612,−236.6211)`。把“左手骨不自转”说成“手掌世界位置不动”会直接导致火线挂错位置。

S1 使用整段 0–60 帧。聚火跟随抬掌，收掌时按真实攻击事件点火，随后进入余焰与放手。它没有剑击主动作，因此 S1 不能再同时绘制一套普通劈砍刀光，伪装成“先挥剑再施法”。该次强化攻击的机制仍只结算一次。

### Skill_2：长蓄势后的身体前压重斩，随后抬剑回弹

0–32 帧收拢左臂并调整低位剑；32–45 帧抬剑到肩后；45–72 帧是相当长的肩后准备；72–75 帧转身压低并发力；75–80 帧快速向前劈剑，第 77 帧触发 `OnAttack`；80–95 帧明显抬剑回弹；95–110 帧身体和剑回到待机附近。

2.4 秒剑仍横在肩后，2.5 秒转为举剑，2.5667 秒剑前送，2.6 秒劈到身体前下方，2.6667 秒已经抬回。胸部自身旋转幅度为 17.0236°，头部为 13.8665°，配合腰部和网格，能看到比 `Attack_2` 更明确的躯干前压。这里才有可复用的重斩主体。

S3 每次真实攻击使用整段 0–110 帧，单独压缩前奏和肩后长准备，保留前劈、回弹、归位。回弹是同一刀的余势，源第 80 帧之后关闭新的剑路发射，不能再次命中、发火墙或播重斩声。

这段并非起飞或展翼。将完整 3.6667 秒压成 0.45/0.55 游戏秒作为开技动作，会把重斩和回弹一并快放，接着真实第一刀又来一次。规格取消独占的 `Skill_2` 开技段，只让真实 S3 攻击调用一次该片段。

### Die：站立收剑与分部位消失，没有倒地

0–22 帧是短暂受创起伏；22–55 帧剑转到体前再收回；55–60 帧举成竖剑；60–135 帧仍站着，身体、左手和尾巴继续运动；135–147 帧开始分部位变暗、透明；147–150 帧是透明尾段。连续画面没有完整侧翻、跪倒、身体接地或可保留的尸体姿势。

透明度来自各插槽自己的颜色轨道。例如后裙从源 4.5333 至 4.6667 秒淡出，裙体从 4.5667 至 4.7 秒淡出，剑从 4.6333 至 4.8 秒淡出，部分头发在 4.6667–4.8 秒淡出；尾巴等仍可见到更后面。不能提前认为“剑消失就整个人消失”。

阵亡选完整 0–150 帧，以 2.5 倍源速率单次播放，共 2 游戏秒。保留其站立消失的真实形态，不声称有倒地，也不在收剑时产生攻击刀光。最后保持透明并移除表现。撤退另用冻结淡出，不反放 `Die` 造成部件逐个重生。

## 每一刀怎样压进现有时间

所有攻击表以真实命中为 `t=0`，起手在负时间，收势在正时间。源事件只提供姿势相位，不能反过来触发伤害、重复音效或额外攻击。普通与 S2 的命中相位为 40/70≈0.571429，S1 为 30/60=0.5，S3 为 77/110=0.7；不再用同一个 `hitPhase=0.305833` 同时代表四种不同素材与游戏时间。

设真实攻击间隔为 `I`，本次能得到的提前量为 `A`。实际起手长度 `L=min(A,0.28,0.28×I)`，下次预留起手长度 `Lnext=min(0.28,0.28×I)`。收势长度 `R=min(该档默认收势,I−Lnext)`，并将下限截为 0。默认收势分别为普攻 0.54、S1 0.50、S2 0.48、S3 0.70 游戏秒。多出来的间隔回到待机，不在源末帧僵住一整轮。

起手表横轴是从 `t=−L` 到 `0` 的归一化进度，纵轴是源帧；收势表横轴是从 `0` 到 `R` 的归一化进度。段内线性推进源时间，再由原始骨骼曲线求姿势，不能把姿势关键值也改成线性骨骼运动。

| 档位 | 起手进度 → 源帧 | 收势进度 → 源帧 |
| --- | --- | --- |
| 普攻 / S2 | 0→0，0.25→16，0.60→37，0.72→39，1→40 | 0→40，0.18→42，0.32→44，0.65→55，1→70 |
| S1 | 0→0，0.45→8，0.85→28，1→30 | 0→30，0.20→37，0.50→52，0.76→55，1→60 |
| S3 | 0→0，0.20→32，0.45→45，0.60→72，0.78→75，1→77 | 0→77，0.13→79，0.23→80，0.49→95，1→110 |

例如普攻提前量为 0.28 秒时，第 39 帧在命中前约 0.0784 秒到达，第 40 帧在真实命中时到达，第 44 帧在命中后约 0.1728 秒到达，余下时间收剑归位。S2 采用同一路径，主要压短收势。S3 会把源 0–2.4 秒的前奏压进约 0.168 游戏秒；这会牺牲原素材长蓄势的重量感，属于现有提前量下的取舍。实际前劈与回弹单独分配时间，不能将整段匀速快放，也不能声称保留了原速蓄势。

提前起手与真实攻击必须接在同一轨道上。真实事件到来时将源时间校准到该档命中相位，绑定本次 `attackId`，不能重新从源 0 开始，也不能把已播完的起手倒回去。重复的预起手请求只更新剩余时间，不重启动作。

## 首刀没有足够提前量时

普攻、S1、S2 的可读起手下限定为 0.10 游戏秒，S3 为 0.16 游戏秒。这里的下限只决定是否保留起手装饰与起手声音，不是禁止发动攻击的门槛。只要 `L>0`，仍按同一张表从源 0 单调压到命中相位，混入时长取 `min(0.06,L/4)`，在命中前结束。可用时间越短，起手越急；不能用延后结算掩盖这个事实。

`L=0` 时，真实事件立即产生目标命中反馈。角色在 `min(1/30,R)` 游戏秒内，从当前姿势混到对应素材的命中姿势；这段时间固定源相位，之后用剩余收势时间播完尾段。该刀省去大范围移动刀光、剑路拖尾和补播的起手音。最多 1/30 秒的角色姿势追赶是明确接受的表现缺口，不虚构已经发生的完整挥剑路径，也不让远处目标等动画才掉血。

目标消失、攻击取消或受到控制而没有产生真实攻击事件时，预起手以 0.08 秒混回当前技能待机，不发命中特效、火墙或攻击完成音。预起手本身不能消费 S1 pending。下一次真实攻击优先于旧收势，必要时截短旧尾段；不排队等待上一段播完。

## 状态切换、打断与起落

同一帧的主体优先级为：真实阵亡、撤退、禁止行动的受控、已确认攻击、预起手、待机。伤害已经发生的目标反馈保留；角色主体不能因“动作不可打断”而忽视死亡或受控。

| 转换 | 混入时长（游戏秒） | 具体规则 |
| --- | ---: | --- |
| 入场 / 待机 → 攻击 | min(0.06,L/4) | 从当前最终姿势混入；命中前必须完成混入 |
| 攻击 → 待机 | 普攻/S1/S2 为 0.08，S3 为 0.10 | 源打击窗结束后允许收束；下次攻击将至时截短混出 |
| 旧攻击 → 新攻击 | min(0.04,L/4) | 新的真实攻击优先，旧收势不占行动锁 |
| 任意存活状态 → 受控 | 0 | 冻结当下完整求值姿势，取消未确认的起手 |
| 受控解除 → 当前技能待机 | 0.10 | 不续播旧攻击，不补放受控期间错过的攻击 |
| 任意存活状态 → 阵亡 | 0.05 | 切入 Die，终止主体攻击效果，之后不回待机 |
| 任意存活状态 → 撤退 | 0 | 冻结当前姿势，外层淡出 0.18 秒 |
| 技能开启 / 结束 | 不另切独占骨骼段 | 更新选片与技能投影；不会因瞬时 off 切掉已确认的 S1 |
| 起飞 / 落地 | 不另切独占骨骼段 | 外层高度变化与当前骨骼动作并行 |

已确认攻击在普通 idle 请求或技能 off 后继续到有效打击窗末端，再混回当前技能待机：`Attack_2` 到第 44 帧，S3 到 `Skill_2` 第 80 帧，S1 的收势按其单次表完成。真实受控、阵亡和撤退立即打断。技能在命中前切换时，以新的真实候选片段对应的剩余起手相位衔接；若事件到来才知道 S1 被消耗，则使用无提前量追赶，不能再从头补一套施法。

受控以引擎 `canAct=false` 为准。沉默、减速不能被表现层自行解释成停攻。控制解除保留真实技能、pending 和飞行投影，回到对应待机；解除控制不重播开技动作。重建时若没有可冻结的姿势，明确使用 `Idle(0)`，不能停在未求值的设置姿势。

素材没有 rise、land 或 wing。S2/S3 起飞只读取真实 `talula:liftoff` 投影：角色外层高度目标为 0.35 格，0.35 游戏秒上升、0.30 游戏秒下降，从当前高度平滑接到目标。飞行空闲摆动幅度 0.03 格，周期 1.6 游戏秒；受控时停装饰摆动，真实高度目标仍按 buff 保留。中途反向从当前高度继续，不先跳回地面。S1 不额外起飞。

这些高度变化是外层表现，不是原生起落骨骼。角色、剑、手部与随身特效共用同一外层变换。地面火和机制火墙使用自己的地面坐标，不能跟着身体上下漂。死亡时已有浮空高度在 0.30 秒内回到地面，不称为素材中的摔落动作。

## 剑路、掌位与火效的共同依据

取最终求值后的 `R_Weapon.matrix`，变换骨局部 `(0,0)` 与 `(336.371002,0)` 两点，得到剑轴两端。再应用角色朝向镜像、缩放、外层高度和场景投影，计算屏幕剑轴方向。相邻样本的角度差按有符号短差展开，不能直接读取恒为 0 的旋转动画偏移，也不能硬编码朝右时必须正转或反转。低帧率越过整个打击窗时省掉补画的大弧，不用两端角度补成一个整圈。

普攻与 S2 只在源第 39–44 帧记录攻击剑路，S3 只在第 75–80 帧记录；之后的收剑、回弹都不再生成新刀光。随剑火痕延迟 0.06 游戏秒，使用真实剑路的延迟历史形成拖尾，满足剑先经过、火后留下。范围刀光沿同一组剑路样本展开，取消独立 0.42 秒推进时钟。使用新增纹理刀痕时，持续屏蔽 `F_R_Weapon_E` 原生灰色刀痕；每次姿势求值后都需要应用遮罩，初始化时置空一次会被附件轨道恢复。

S1 使用 `L_Hand` 局部中点 `(20.878971,0)` 作为掌内侧聚火挂点，读取最终世界矩阵。这个点是按手骨长度二分选出的接入位置，不是素材自带特效骨。掌在命中时换成拳，挂点仍存在于同一根手骨上，不会因掌附件消失而跳到脚下。S1 不画普通剑路，其顺序是抬掌聚火、真实命中时收掌、火线与目标余焰。

目标上的即时命中标记保留在真实事件时刻；延迟只作用于装饰火痕。S3 火墙的生成与波前沿用真实 `waveId/front`，不能为了装饰的 0.06 秒滞后推迟真实火墙或伤害。全场远处目标只播放真实受击反馈，不把本地剑轴跨屏连到每个目标。

## 接入边界与验收状态

本规格只使用现有八段素材，不生成新骨骼曲线。没有专用动作的入场、起落、受控、撤退分别采用显现、外层高度、当前姿势定格和淡出补偿；阵亡接受原素材站立消失的形态。所有单次攻击由真实 `sourceId + attackId` 去重，技能开始由 `activationId` 去重；原生 Spine 事件不直接驱动机制或额外声音。

现有 0.28 秒公共提前起手上限可沿用。新的源时间表、S1 pending 绑定、S3 单次重斩、死亡速率和撤退冻结需要由角色表现接线执行；把本 JSON 放入目录本身不会改变运行效果。伤害、索敌、SP、攻击间隔、施法窗口、部署延迟、随机源与存档格式均不属于本规格的修改对象。

已完成的是官方素材实测、九类状态及其衔接参数。接入后的混入观感、极短首刀、镜像剑路、死亡速率和暂停倍速表现由 DSH 侧实机验收；本文不将离线姿势观察写成游戏效果已经通过验收。
