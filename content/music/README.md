# 背景音乐

本目录提供 OGG 背景音乐，随源码分发。使用 Git 克隆或下载 GitHub 源码 ZIP，即可获得曲目。

关卡编辑器可选择这里的曲目作为作战音乐；局外全局设置也使用同一目录，默认《生命流》。新增 OGG 后，打开全局设置或点击「刷新曲目」即可读取，无需重启服务。选择保存在当前浏览器中。

主菜单、三个二级入口与实际关卡编辑界面共用一条局外音乐，切页不中断。开关音乐、静音或将音量调到零会保留当前位置，恢复时继续播放；调整其他音量也不重新加载曲目。进入或离开战斗、手动换曲时从头播放。首次出声需先点击页面或按键。

带 `LOOPSTART`、`LOOPLENGTH` 的曲目按指定段落循环，播放器以 `LOOPSAMPLERATE` 或 Vorbis 源采样率换算；无标记时整曲循环。《生命流》的前奏只播放一次，后续重复循环段。
